# Plan 01-01: Foundation, Relational Database Schema & Scaffolding

## Goal
Scaffold the complete React 18+ Vite application with Tailwind CSS, set up project dependencies, create the production-grade PostgreSQL Supabase migration covering all 11 tables with RLS and triggers, and build the resilient Supabase client layer.

## Proposed Changes
1. **Scaffold Project**:
   - `package.json`: React 18, Vite, Tailwind CSS, `@supabase/supabase-js`, `lucide-react`, `react-router-dom`, `xlsx`, `tesseract.js`, `canvas-confetti`.
   - `vite.config.js`, `tailwind.config.js`, `postcss.config.js`, `index.html`.
2. **Database Schema**:
   - `supabase/migrations/20261111000000_init_mechanexus.sql`:
     - Profiles (`profiles`)
     - Membership Applications (`membership_applications`)
     - Community Posts (`community_posts`)
     - Teams (`teams`)
     - Team Members (`team_members`)
     - Projects (`projects`)
     - Project Components (`project_components`)
     - Project Edit History (`project_history`)
     - Tasks (`tasks`)
     - Task Assignments (`task_assignments`)
     - Task Records / Work Items (`task_records`)
     - Events & Workshops (`events`)
     - Event Responsibilities (`event_responsibilities`)
     - Activity Logs (`activity_logs`)
     - Storage Buckets (`avatars`, `project-files`, `event-posters`, `task-attachments`)
     - RLS Policies for each role
3. **Data Layer**:
   - `src/lib/supabase.js`: Supabase client initialization.
   - `src/lib/initialSeed.js`: Rich, authentic demonstration seed data for MITE Mechatronics club.
   - `src/context/ClubContext.jsx`: Reactive data layer that synchronizes with Supabase when configured, or transparently persists state locally when offline/pending keys.
   - `.env.example`: Template for Supabase credentials.

## Verification
- `npm install` and `npm run build` succeeds cleanly.
- Migration file is syntactically valid PostgreSQL DDL.
